# Ad Targeting — Predicting Ad Clicks (NSDC Data Science Project)

> A guided classification project from the National Student Data Corps: explore user demographics and browsing behavior, then predict which users will click an online ad.

[![Python](https://img.shields.io/badge/Python-3-blue.svg)](https://www.python.org/) [![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## Overview & motivation

Advertisers want to show ads to the people most likely to engage. Using the public Kaggle "advertising" dataset (~1,000 users: age, area income, daily time on site, daily internet usage, gender, timestamp), the notebook explores what separates clickers from non-clickers and fits a classifier.

## Approach & tech stack

- Data cleaning and EDA (distributions, correlations, click rate by segment)
- Feature preparation and a logistic-regression classifier with scikit-learn
- **Stack:** Python · pandas · Matplotlib/Seaborn · scikit-learn · Jupyter / Google Colab

## How to run

Open `Ad_Targeting.ipynb` in Google Colab or Jupyter and run all cells.
